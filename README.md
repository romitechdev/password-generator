# Password Generator

A password generator web app with configurable length and character sets.

## Features

- Adjustable password length
- Configurable character sets (uppercase, lowercase, numbers, symbols)
- Instant password generation
- Clean, minimal UI

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```
.
├── index.html
├── index.js
└── img/
```

## Getting Started

Open `index.html` in a browser.
